# OptmizerControl
OptimizerControl
O OptimizerControl é um utilitário de otimização de sistema desenvolvido para usuários que buscam performance e controle granular sobre o Windows. Diferente de scripts automáticos genéricos, esta ferramenta prioriza a transparência e a segurança, permitindo que o usuário compreenda exatamente quais alterações estão sendo realizadas no núcleo do sistema.

🚀 Funcionalidades Principais
Modo Automático: Execução rápida das rotinas essenciais de manutenção para usuários que buscam praticidade.

Modo Manual (Granular): Controle total sobre cada etapa, com explicações técnicas detalhadas sobre os impactos de cada operação.

Segurança em Primeiro Lugar: Verificação de privilégios de administrador integrada para garantir a integridade das operações.

Manutenção de Rede: Limpeza de cache DNS e reset de Winsock para reduzir latência e falhas de conexão.

Integridade do Sistema: Integração nativa com SFC e DISM para reparo de arquivos corrompidos.

📋 Diretrizes de Operação (Importante)
Para manter a longevidade do seu hardware e a estabilidade do sistema, o OptimizerControl deve ser utilizado com consciência:

Periodicidade Recomendada: Execute o utilitário a cada 30 ou 45 dias.
Limpezas de cache diárias ou semanais são contraproducentes e podem causar latência desnecessária, forçando o sistema a reconstruir rotas e logs que já estão otimizados.

🛠️ Como Utilizar
Baixe a versão mais recente na seção de Releases.

Clique com o botão direito no OptimizerControl.exe.

Selecione "Executar como administrador".

Siga as instruções na tela e escolha entre o modo Automático ou Manual.

🛡️ Transparência e Código Aberto
Acreditamos na segurança através da transparência. O código-fonte original (.bat) está disponível neste repositório. Você é livre para auditar cada comando antes de executar o executável (.exe), garantindo total confiança no que está sendo aplicado em sua máquina.
